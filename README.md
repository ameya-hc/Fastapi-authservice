# User Authentication API

This project is a user authentication API that includes user registration, login using JWT authentication, token refresh, PostgreSQL database integration, and Dockerized deployment for ease of setup and deployment.

## Features

- ✅ **User Registration (Signup)**
- 🔐 **User Login with JWT Authentication**
- 🔄 **Token Refresh Mechanism**
- 🗃️ **Database Integration using PostgreSQL**
- 🐳 **Dockerized Deployment**

## Technologies Used

- Python / Django or Flask (depending on your backend)
- PostgreSQL
- JWT (JSON Web Token)
- Docker & Docker Compose
